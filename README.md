# 일출 · 일몰 시각

오늘(한국 시간) 우리나라 주요 지역의 **해 뜨는 시각**과 **해 지는 시각**을 보여 주는 웹페이지입니다.

🔗 **사이트:** https://week-12-amber.vercel.app

## 기능

화면 순서: **고른 지역 시각 → 네 칸 정보 → 지역 선택(지도 · 목록) → 전국 순위 → 월별 달력**

- 보기 3가지: **오늘** · **새해 첫 일출**(다음 해 1월 1일) · **올해 마지막 일몰**(올해 12월 31일) — 날짜는 한국 시간 기준으로 자동 계산
- 배경: 오늘 · 새해 첫 일출은 남색 → 주황색, 올해 마지막 일몰은 보라색 → 붉은색 그라데이션
- 맨 위에 고른 지역 시각을 크게 (오늘 보기는 일출 · 일몰 나란히, 지난 시각은 흐리게)
- 네 칸: 밝아지는 시각(`civilm`) · 어두워지는 시각(`civile`) · 낮 길이 · 남은 시간(1초마다 갱신)
- **지역 선택**: 64곳을 지도(점) 또는 목록(권역별)으로 고르기, 이름 검색, 골라도 화면이 움직이지 않음
  - 지도의 점은 순위 기준(해 뜨는/지는 시각)에 따라 주황(빠름) ~ 남색(늦음)으로 색칠
- **전국 순위**: 64곳을 '빨리 뜨는 순' · '늦게 지는 순'으로 정렬, 고른 지역의 순위와 1위와의 차이 표시, 줄을 누르면 그 지역 선택
- 마지막으로 고른 지역 · 보기 · 지도/목록 · 달력/표를 기억
- 선 아이콘(SVG), 데스크톱 · 태블릿 · 모바일 화면에 맞춘 배치
- **월별 일출 · 일몰**: 고른 지역의 한 달치를 달력 또는 표(날짜 · 해 뜨는 시각 · 해 지는 시각 · 낮 길이)로 보기
  - 처음엔 이번 달, 이전 달 · 다음 달 버튼으로 올해 1월 ~ 내년 12월까지 이동
  - 오늘 칸은 색으로, 1월 1일 · 12월 31일 칸은 테두리로 표시
- 오류가 나면 한국어로 안내 (인증키 문제, 요청 한도 초과, 서버 연결 실패 등)

## 구조

```
Week_12/
├── index.html        # 화면 (HTML + CSS + JS)
├── api/sunrise.js    # Vercel 함수: 하루치 조회 → JSON (하루 캐시)
├── api/month.js      # Vercel 함수: 한 달치를 150ms 간격으로 하루씩 조회 → JSON (30일 캐시)
├── api/rank.js       # Vercel 함수: 그날 64개 지역을 150ms 간격으로 조회 → JSON (30일 캐시)
├── api/_kasi.js      # 공통 코드: API 호출 · XML 해석 · 오류 안내 · 150ms 줄 세우기 (함수로 배포되지 않음)
├── vercel.json       # 함수 지역을 서울(icn1)로, month · rank 함수 최대 실행 시간 60초
├── dev-server.js     # 내 컴퓨터 테스트용 작은 서버 (배포에는 포함되지 않음)
├── .vercelignore     # 배포에서 제외할 파일
└── .gitignore        # .env.local 등 비밀 파일 제외
```

```
브라우저 ──▶ /api/sunrise?location=서울&date=YYYYMMDD ──▶ 한국천문연구원 API
   ◀── { sunrise: "07:22", sunset: "17:16", ... } ◀── XML
```

- 인증키는 코드에 없고, 서버 함수가 환경 변수 `DATA_GO_KR_KEY`에서만 읽습니다. 브라우저에는 노출되지 않습니다.
- 같은 날짜·지역 요청은 **하루 동안 캐시**합니다 (Vercel CDN `s-maxage=86400` + 함수 메모리 캐시).
- 월별 조회(`/api/month?location=서울&ym=202611`)는 공공데이터포털이 한꺼번에 많은 요청을 막지 않도록 **150ms 간격으로 하나씩** 부르고, 결과를 **30일 동안 캐시**합니다. 처음 조회할 때는 몇 초 걸립니다.
- 전국 순위(`/api/rank?date=20261125`)도 같은 방식으로 64곳을 부르고 30일 동안 캐시합니다. 처음엔 15~20초 걸립니다.
- 지도 위치는 API 응답의 경도 · 위도(`longitudeNum`, `latitudeNum`)를 쓰고, 해안선은 대략적으로 그린 것입니다.

## 사용한 API

공공데이터포털 · 한국천문연구원 **출몰시각 정보** — `getAreaRiseSetInfo`

| 요청 값 | 설명 |
|---|---|
| `locdate` | 날짜 (예: `20261125`) |
| `location` | 지역 이름 (예: `서울`) |
| `serviceKey` | 공공데이터포털 인증키 |

## 내 컴퓨터에서 실행하기

1. [공공데이터포털](https://www.data.go.kr)에서 *한국천문연구원_출몰시각 정보* 활용 신청 후 인증키를 받습니다.
2. `Week_12` 폴더에 `.env.local` 파일을 만들고 키를 넣습니다. (Encoding·Decoding 키 둘 다 됩니다)
   ```
   DATA_GO_KR_KEY=여기에_인증키
   ```
3. [Node.js](https://nodejs.org)를 설치한 뒤 실행합니다.
   ```powershell
   node dev-server.js
   ```
4. 브라우저에서 http://localhost:3000 을 엽니다.

> `vercel dev`로도 실행할 수 있지만, Windows에서는 개발자 모드가 꺼져 있으면 심볼릭 링크 오류가 납니다. 그럴 땐 `dev-server.js`를 쓰세요.

## Vercel 배포

1. Vercel 프로젝트 **Settings → Environment Variables**에 `DATA_GO_KR_KEY`를 추가합니다.
2. 이 저장소가 Vercel과 연결되어 있어서 `main` 브랜치에 push하면 자동으로 다시 배포됩니다.
   (직접 배포: `vercel deploy --prod`)

> ⚠️ PowerShell에서 `키 | vercel env add ...`처럼 파이프로 키를 넣으면 끝에 보이지 않는 문자(`\r`)가 붙어 **"등록되지 않은 서비스키"** 오류가 날 수 있습니다. 대시보드에서 직접 입력하거나 `--value` 옵션을 쓰세요.
