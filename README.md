# 일출 · 일몰 시각

우리나라 64개 지역의 **해 뜨는 시각**과 **해 지는 시각**을 한국천문연구원 자료로 보여 주는 웹페이지입니다.
오늘 · 새해 첫 일출 · 올해 마지막 일몰을 보고, 지도로 지역을 고르고, 전국 순위와 월별 달력까지 볼 수 있습니다.

- **사이트:** https://week-12-amber.vercel.app
- **저장소:** https://github.com/kmforce71-art/week-12

## 화면 구성

위에서 아래로 **① 고른 지역 시각 → ② 네 칸 정보 → ③ 지역 선택 → ④ 전국 순위 → ⑤ 월별 달력** 순서입니다.

### 보기 3가지

| 보기 | 날짜 (한국 시간 기준 자동 계산) | 크게 보여 주는 시각 | 배경 |
|---|---|---|---|
| 오늘 | 오늘 | 해 뜨는 시각 · 해 지는 시각 나란히 (지난 시각은 흐리게) | 남색 → 주황색 |
| 새해 첫 일출 | 다음 해 1월 1일 | 해 뜨는 시각 | 남색 → 주황색 |
| 올해 마지막 일몰 | 올해 12월 31일 | 해 지는 시각 | 보라색 → 붉은색 |

### ① ② 고른 지역 시각과 네 칸 정보

- **밝아지는 시각** (`civilm`, 시민박명 시작) · **어두워지는 시각** (`civile`, 시민박명 끝)
- **낮 길이** = 해 지는 시각 − 해 뜨는 시각
- **남은 시간**을 `4시간 12분 5초`처럼 1초마다 갱신
  - 오늘 보기: 다음 일출이나 일몰까지, 해가 졌으면 내일 일출까지
  - 나머지 보기: 그 시각까지

### ③ 지역 선택 (지도 · 목록)

- **지도**: 64곳을 점으로 표시. 점 색은 순위 기준에 따라 주황(빠름) ~ 남색(늦음)
- **목록**: 수도권 · 강원 · 충청 · 전라 · 경상 · 제주 권역별로 묶은 버튼
- 이름으로 검색 (지도에서는 맞지 않는 점이 흐려짐)
- 지역을 골라도 화면이 위로 이동하지 않음

| 권역 | 지역 |
|---|---|
| 수도권 | 서울 인천 수원 평택 |
| 강원 | 강릉 속초 동해 대관령 태백 춘천 원주 영월 |
| 충청 | 대전 세종 천안 청주 청주공항 충주 제천 보령 서산 추풍령 |
| 전라 | 광주 전주 군산 정읍 부안 남원 임실 장수 목포 무안 여수 여수공항 순천 승주 고흥 장흥 완도 해남 흑산도 |
| 경상 | 부산 대구 울산 포항 경주 영덕 울진 독도 안동 영주 춘양 상주 김천 의성 영천 밀양 진주 통영 거제 남해 거창 |
| 제주 | 제주 서귀포 |

### ④ 전국 순위

- 지금 보기의 날짜로 64곳을 **빨리 뜨는 순** 또는 **늦게 지는 순**으로 정렬
- 고른 지역의 순위와 1위와의 차이(분)를 위에 표시
- 순위 줄을 누르면 그 지역이 선택됨

### ⑤ 월별 일출 · 일몰

- 고른 지역의 한 달치를 **달력** 또는 **표**(날짜 · 해 뜨는 시각 · 해 지는 시각 · 낮 길이)로 보기
- 처음엔 이번 달, 이전 달 · 다음 달 버튼으로 올해 1월 ~ 내년 12월까지 이동
- 오늘 칸은 색으로, 1월 1일 · 12월 31일 칸은 테두리로 표시

### 그 밖에

- 마지막으로 고른 지역 · 보기 · 지도/목록 · 달력/표를 기억 (브라우저 localStorage)
- 이모지 대신 선 아이콘(SVG) 사용
- 데스크톱(지역 선택과 순위 나란히) · 태블릿 · 모바일(네 칸 2×2) 화면에 맞춘 배치
- 오류가 나면 한국어로 안내 (인증키 문제, 요청 한도 초과, 서버 연결 실패 등)

## 구조

```
Week_12/
├── index.html        # 화면 (HTML + CSS + JS, 지도 · 아이콘 포함)
├── api/
│   ├── sunrise.js    # 하루치 조회 (하루 캐시)
│   ├── month.js      # 한 달치를 150ms 간격으로 하루씩 조회 (30일 캐시)
│   ├── rank.js       # 그날 64개 지역을 150ms 간격으로 조회 (30일 캐시)
│   └── _kasi.js      # 공통 코드: API 호출 · XML 해석 · 오류 안내 · 150ms 줄 세우기
│                     #   ('_'로 시작해서 함수로 배포되지 않음)
├── vercel.json       # 함수 지역 서울(icn1), month · rank 최대 실행 시간 60초
├── dev-server.js     # 내 컴퓨터 테스트용 작은 서버 (배포에는 포함되지 않음)
├── .vercelignore     # 배포에서 제외할 파일
└── .gitignore        # .env.local 등 비밀 파일 제외
```

```
브라우저 ──▶ /api/sunrise · /api/month · /api/rank ──▶ 한국천문연구원 API (XML)
   ◀──────────── 필요한 값만 JSON ◀──────────────
```

## 서버 함수 (Vercel)

| 주소 | 하는 일 | 캐시 |
|---|---|---|
| `/api/sunrise?location=서울&date=20261125` | 하루치 일출 · 일몰 · 박명 시각 | 1일 |
| `/api/month?location=서울&ym=202611` | 한 달치 (하루씩 150ms 간격) | 30일 |
| `/api/rank?date=20261125` | 그날 64개 지역 전부 (150ms 간격) | 30일 |

- 인증키는 코드에 없고, 서버 함수가 환경 변수 `DATA_GO_KR_KEY`에서만 읽습니다. 브라우저에는 노출되지 않습니다.
- 공공데이터포털은 한꺼번에 많이 부르면 잠시 막기 때문에, 여러 번 부를 때는 **150ms 간격으로 하나씩** 부릅니다.
- 캐시는 Vercel CDN(`s-maxage`)과 함수 메모리 두 곳에 둡니다. 처음 조회는 월별 약 7초, 전국 순위 약 15초 걸리고, 그다음부터는 바로 나옵니다.
- 조회할 수 있는 날짜는 올해 1월 1일 ~ 내년 12월 31일입니다.
- 지도 위치는 API 응답의 경도 · 위도(`longitudeNum`, `latitudeNum`)를 썼고, 해안선은 대략적으로 그린 것입니다.

## 사용한 API

공공데이터포털 · 한국천문연구원 **출몰시각 정보** — `getAreaRiseSetInfo`

| 요청 값 | 설명 |
|---|---|
| `locdate` | 날짜 (예: `20261125`) |
| `location` | 지역 이름 (예: `서울`) |
| `serviceKey` | 공공데이터포털 인증키 |

| 응답 값 | 뜻 |
|---|---|
| `sunrise` / `sunset` | 해 뜨는 시각 / 해 지는 시각 (`0722` 형식) |
| `civilm` / `civile` | 하늘이 밝아지는 시각 / 어두워지는 시각 |

> 요청 수: 지역 하나의 한 달은 약 30회, 전국 순위 하루치는 64회를 씁니다. 같은 조회는 30일 동안 캐시되므로 다시 쓰지 않습니다.

## 내 컴퓨터에서 실행하기

1. [공공데이터포털](https://www.data.go.kr)에서 *한국천문연구원_출몰시각 정보* 활용 신청 후 인증키를 받습니다.
2. `Week_12` 폴더에 `.env.local` 파일을 만들고 키를 넣습니다. (Encoding · Decoding 키 둘 다 됩니다)
   ```
   DATA_GO_KR_KEY=여기에_인증키
   ```
3. [Node.js](https://nodejs.org)를 설치한 뒤 실행합니다.
   ```powershell
   node dev-server.js
   ```
4. 브라우저에서 http://localhost:3000 을 엽니다.

> `vercel dev`로도 실행할 수 있지만, Windows에서 개발자 모드가 꺼져 있으면 심볼릭 링크 오류(`EPERM`)가 납니다. 그럴 땐 `dev-server.js`를 쓰세요.

## Vercel 배포

1. Vercel 프로젝트 **Settings → Environment Variables**에 `DATA_GO_KR_KEY`를 추가합니다.
2. 이 저장소는 Vercel과 연결되어 있어서 `main` 브랜치에 push하면 자동으로 다시 배포됩니다.
   (직접 배포: `vercel deploy --prod`)

> **주의:** PowerShell에서 `키 | vercel env add ...`처럼 파이프로 키를 넣으면 끝에 보이지 않는 문자(`\r`)가 붙어 **"등록되지 않은 서비스키"** 오류가 날 수 있습니다. 대시보드에서 직접 입력하거나 `--value` 옵션을 쓰세요.
